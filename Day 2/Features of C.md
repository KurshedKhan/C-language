# Features of C Programming Language

C is a powerful and versatile programming language that is widely used in system programming, embedded systems, and application development.

---

## 🔹 1. Simple and Efficient
- C has a small set of keywords and clear syntax.
- Programs are easy to write and understand.

---

## 🔹 2. Fast and Powerful
- C provides low-level memory access.
- It is highly efficient and produces fast-executing programs.

---

## 🔹 3. Portable
- C programs are machine-independent.
- Code written on one machine can run on another with little or no modification.

---

## 🔹 4. Mid-Level Language
- C supports features of both high-level and low-level languages.
- It is suitable for writing system software like operating systems.

---

## 🔹 5. Rich Library
- C provides many built-in functions via standard libraries (like `stdio.h`, `math.h`).

---

## 🔹 6. Modularity
- Large programs can be divided into smaller functions.
- This makes code organized, reusable, and easier to maintain.

---

## 🔹 7. Dynamic Memory Management
- Functions like `malloc()`, `calloc()`, and `free()` allow manual memory allocation and deallocation.

---

## 🔹 8. Structured Language
- Supports structured programming using functions, loops, conditionals, etc.
- Encourages clear and logical program structure.

---

## 🔹 9. Extensible
- C allows the addition of new features and libraries easily.

---
