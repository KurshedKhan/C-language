# C Language – Basic Syntax with Detailed Explanation

## ✅ Example: Basic C Program

```c
#include <stdio.h>  
int main() {
    printf("Hello, World!");
    return 0;
}
```

---

## 🔍 Line-by-Line Explanation

### 1. `#include <stdio.h>`

- Preprocessor directive.
- Tells the compiler to include Standard Input Output library.
- Allows use of `printf()` and `scanf()` functions.

---

### 2. `int main() {`

- Starting point of every C program.
- `int` means it returns an integer value.
- `{` marks the beginning of the main block.

---

### 3. `printf("Hello, World!");`

- Used to display output.
- `"Hello, World!"` is a string to be printed.
- Ends with `;` to terminate the statement.

---

### 4. `return 0;`

- Ends the program and returns `0` to the operating system.
- `0` means the program executed successfully.

---

### 5. `}`

- Marks the end of the main function.

---

## 📌 Summary Table

| Term         | Meaning                              |
|--------------|--------------------------------------|
| `#include`   | Include a library header             |
| `main()`     | Starting point of the program        |
| `printf()`   | Function to print text               |
| `return 0;`  | Indicates successful program end     |
| `{}`         | Denotes code block                   |
