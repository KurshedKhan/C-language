# 🧠 C Programming: 50 Interview Questions and Answers

---

## ✅ Basics of C Language

1. **What is C language?**

   * A general-purpose, procedural programming language developed by Dennis Ritchie.

2. **What are the key features of C?**

   * Fast, structured, low-level memory access, portable, and extensible.

3. **What is the difference between compiler and interpreter?**

   * Compiler translates entire code at once. Interpreter translates line-by-line.

4. **What is the use of `main()` function?**

   * It's the entry point of a C program.

5. **What are keywords in C?**

   * Reserved words (e.g., `int`, `return`, `if`) used for specific functionalities.

6. **What are identifiers?**

   * Names used for variables, functions, arrays, etc.

7. **What is the size of `int` in C?**

   * Typically 4 bytes (depends on system).

8. **What is a variable in C?**

   * A named space in memory to store a value.

9. **What is a constant in C?**

   * A fixed value that does not change during execution.

10. **What is a data type?**

    * Specifies the type of data (e.g., `int`, `char`, `float`).

---

## ✅ Control Structures

11. **What is `if` statement?**

    * Executes a block of code if the condition is true.

12. **What is a `switch` statement?**

    * Selects one of many code blocks to be executed.

13. **What is a loop?**

    * Repeats a block of code multiple times.

14. **Types of loops in C?**

    * `for`, `while`, `do-while`

15. **Difference between `while` and `do-while`?**

    * `do-while` runs at least once; `while` may not run.

16. **What is `break` and `continue`?**

    * `break` exits loop; `continue` skips iteration.

17. **What is a nested loop?**

    * A loop inside another loop.

18. **What is the use of `goto`?**

    * Transfers control to a labeled statement.

---

## ✅ Functions

19. **What is a function?**

    * A reusable block of code.

20. **Types of functions in C?**

    * Built-in and user-defined.

21. **What is `return` statement?**

    * Ends function and optionally returns a value.

22. **What is recursion?**

    * A function calling itself.

23. **What is a function prototype?**

    * Declaration of a function before its use.

24. **What are arguments and parameters?**

    * Arguments are actual values; parameters are variables used to receive them.

25. **What is call by value?**

    * Passing a copy of variable to function.

---

## ✅ Arrays & Strings

26. **What is an array?**

    * A collection of elements of same type.

27. **Types of arrays?**

    * 1D, 2D, and multi-dimensional arrays.

28. **What is a string in C?**

    * A 1D array of characters ending with null `\0`.

29. **How to declare and initialize an array?**

    * `int a[5] = {1, 2, 3, 4, 5};`

30. **How to find length of a string?**

    * Using `strlen()` function.

---

## ✅ Pointers

31. **What is a pointer?**

    * A variable that stores the address of another variable.

32. **How to declare a pointer?**

    * `int *ptr;`

33. **What is `NULL` pointer?**

    * A pointer that points to nothing (0).

34. **What is pointer arithmetic?**

    * Operations like `ptr++`, `ptr--` to navigate memory.

35. **What is the use of `*` and `&`?**

    * `*` dereferences pointer; `&` gives address.

36. **What is dangling pointer?**

    * A pointer that points to a freed memory location.

---

## ✅ Structures & Unions

37. **What is a structure?**

    * A user-defined data type that can hold different data types.

38. **Syntax of defining structure?**

    * `struct Student { int id; char name[20]; };`

39. **What is a union?**

    * Similar to structure but shares same memory for all members.

40. **Difference between structure and union?**

    * Structure allocates separate memory; union shares memory.

---

## ✅ File Handling

41. **What is file handling in C?**

    * Operations like reading/writing data to files.

42. **Modes of file opening?**

    * `r`, `w`, `a`, `r+`, `w+`, `a+`

43. **Functions for file I/O?**

    * `fopen()`, `fclose()`, `fread()`, `fwrite()`, `fprintf()`, `fscanf()`

44. **Difference between text and binary file?**

    * Text is readable; binary is not human-readable.

---

## ✅ Miscellaneous

45. **What is `typedef`?**

    * Used to create alias name for data types.

46. **What is `enum`?**

    * A user-defined type for assigning names to constants.

47. **What is preprocessor directive?**

    * Instructions that start with `#`, like `#include`, `#define`

48. **What is `static` keyword?**

    * Retains variable value between function calls.

49. **What is memory leak?**

    * Memory not released using `free()`.

50. **What is the difference between `malloc()` and `calloc()`?**

    * `malloc()` allocates uninitialized memory; `calloc()` allocates and initializes to 0.
